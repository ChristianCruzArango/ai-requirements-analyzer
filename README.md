# AI Requirements Analyzer

Sistema completo de análisis de especificaciones de software usando Inteligencia Artificial.

## 📁 Estructura del Proyecto

### `/evaluation-ia` - Frontend Angular
Aplicación web con dos módulos:
- **Ejercicio 1**: Sistema de consulta de pedidos de licitaciones
- **Ejercicio 2**: Analizador de especificaciones con IA

### `/evaluation-api` - Backend .NET
API RESTful que procesa especificaciones de software con OpenRouter AI y gestiona datos en PostgreSQL.

## 🚀 Inicio Rápido

### Frontend
```bash
cd evaluation-ia
npm install
npm start
```

### Backend
```bash
cd evaluation-api/evaluation-api
dotnet restore
dotnet run
```
